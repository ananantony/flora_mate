1. 设计原则

1. **单点真相**：本文件是 EEPROM 中"可配置参数"的**唯一权威定义**。代码中的 `App_Config` 结构体（`app_config.h`）、`g_factory_config` 默认值、串口命令字段名必须与本文件 1:1 对应。
2. **仅持久化配置**：EEPROM 只存放用户可调配置；运行时日志/统计放 RAM（易失，断电清零），不磨损 EEPROM。
3. **双 Bank 冗余 + CRC**：配置区采用双 Bank + CRC-16，写入过程中突然断电（米家硬切）也不致损坏——旧 Bank 始终可用。
4. **工厂默认硬编码兜底**：EEPROM 全损坏时，固件加载内置 `g_factory_config` 正常运行。
5. **版本可演进**：`version` 字段记录结构版本；改布局时 +1，启动时检测并回退/迁移。
6. **页对齐**：`App_Config` 总长 64 字节，按 AT24C08C 页写边界（16 B/页）由 `bsp_eeprom.c` 自动拆页。

────────────────────────────────────────

2. 配置结构 `App_Config`（64 字节）

> 字段定义与 `app_config.h` 中 `typedef struct App_Config` 严格一致，已用 `_Static_assert(sizeof == 64)` 保证。

### 2.1 元数据区（8 字节）

| 偏移 | 字段名 | 类型 | 默认 | 含义 |
|---|---|---|---|---|
| +0 | `magic` | u16 | `0xFAC3` | 配置识别魔数（错则视为未初始化） |
| +2 | `version` | u8 | `2` | 配置结构版本号（当前 `APP_CONFIG_VERSION=2`） |
| +3 | `reserved0` | u8 | `0` | 对齐填充 |
| +4 | `update_count` | u32 | `0` | 累计保存次数，每次 `cfg save` +1（诊断 EEPROM 损耗） |

### 2.2 浇灌阶梯参数（18 字节）

| 偏移 | 字段名 | 类型 | 默认 | 范围 | 含义 |
|---|---|---|---|---|---|
| +8 | `step_count` | u8 | **4** | 1~8 | PWM 阶梯档数 |
| +9 | `step_duty[0]` | u8 | **35** | 0~95 | 1 档占空比 % |
| +10 | `step_duty[1]` | u8 | **55** | 0~95 | 2 档 |
| +11 | `step_duty[2]` | u8 | **75** | 0~95 | 3 档 |
| +12 | `step_duty[3]` | u8 | **95** | 0~95 | 4 档 |
| +13~+16 | `step_duty[4..7]` | u8×4 | 0 | 0~95 | 5~8 档（`step_count`>4 时启用） |
| +17 | `step_seconds[0]` | u8 | **3** | 1~60 | 1 档持续秒 |
| +18 | `step_seconds[1]` | u8 | **3** | 1~60 | 2 档 |
| +19 | `step_seconds[2]` | u8 | **3** | 1~60 | 3 档 |
| +20 | `step_seconds[3]` | u8 | **3** | 1~60 | 4 档 |
| +21~+24 | `step_seconds[4..7]` | u8×4 | 0 | 1~60 | 5~8 档 |
| +25 | `channel_enable` | u8 | **0x1F** | 0x01~0x1F | bit0~4 = 5 路阀（Z1~Z5）是否参与；`App_Config_Clamp` 保证非 0 |

### 2.3 时序参数（8 字节）

| 偏移 | 字段名 | 类型 | 默认 | 范围 | 含义 |
|---|---|---|---|---|---|
| +26 | `idle_seconds` | u8 | **3** | 1~30 | 上电进入自动浇水前倒计时秒数 |
| +27 | `inter_gap_ms_x10` | u8 | **50** | 1~250 | 路间静默 ×10 ms（默认 500 ms） |
| +28 | `per_channel_timeout_s` | u16 | **90** | 30~120 | 单路软超时秒 |
| +30 | `total_timeout_s` | u16 | **480** | 60~600 | 总任务软超时秒 |
| +32 | `selftest_pulse_ms` | u16 | **50** | 10~200 | 自检短脉冲 ms |

### 2.4 HMI 参数（6 字节）

| 偏移 | 字段名 | 类型 | 默认 | 范围 | 含义 |
|---|---|---|---|---|---|
| +34 | `long_press_ms_x10` | **u16** | **100** | 30~300 | 长按门限 ×10 ms（默认 1000 ms） |
| +36 | `hold_press_ms_x10` | **u16** | **300** | 100~500 | 超长按门限 ×10 ms（默认 3000 ms） |
| +38 | `oled_contrast` | u8 | **128** | 0~255 | OLED 对比度 |
| +39 | `log_level` | u8 | **2** | 0~3 | 日志等级 0=E/1=W/2=I/3=D |

### 2.5 硬件版本（1 字节）

| 偏移 | 字段名 | 类型 | 默认 | 含义 |
|---|---|---|---|---|
| +40 | `hw_version` | u8 | **0x31** | 硬件版本 BCD 编码：高 4 位=主版本，低 4 位=次版本；`0x31` = **V3.1** |

> 软件版本（`FM_FIRMWARE_VERSION_STR = "FloraMate V1.0"`）存于 Flash 常量段，**不入 EEPROM**；硬件版本号随 PCB 变更，故存配置区供上位机/调试口读取。

### 2.6 预留 + 校验（23 字节）

| 偏移 | 字段名 | 类型 | 默认 | 含义 |
|---|---|---|---|---|
| +41 | `reserved1[21]` | u8×21 | 0 | Phase 2/3 扩展预留 |
| +62 | `crc16` | u16 | 运行时计算 | 前 62 字节 CRC-16-CCITT |

### 2.7 C 结构定义（与上表 1:1）

```c
typedef struct __attribute__((packed)) {
    uint16_t magic;                 /* +0  0xFAC3 */
    uint8_t  version;               /* +2  当前 2 */
    uint8_t  reserved0;             /* +3  pad */
    uint32_t update_count;          /* +4  累计写次数 */

    uint8_t  step_count;            /* +8  阶梯档数 1~8 */
    uint8_t  step_duty[8];          /* +9  每档占空比 % */
    uint8_t  step_seconds[8];       /* +17 每档持续秒 */
    uint8_t  channel_enable;        /* +25 bit0~4 = 5 路阀 */

    uint8_t  idle_seconds;          /* +26 上电倒计时秒 */
    uint8_t  inter_gap_ms_x10;      /* +27 路间静默 ×10 ms */
    uint16_t per_channel_timeout_s; /* +28 单路超时秒 */
    uint16_t total_timeout_s;       /* +30 总任务超时秒 */
    uint16_t selftest_pulse_ms;     /* +32 自检脉冲 ms */

    uint16_t long_press_ms_x10;     /* +34 长按阈值 ×10 ms */
    uint16_t hold_press_ms_x10;     /* +36 超长按阈值 ×10 ms */
    uint8_t  oled_contrast;         /* +38 OLED 对比度 */
    uint8_t  log_level;             /* +39 0=E 1=W 2=I 3=D */

    uint8_t  hw_version;            /* +40 BCD：0x31 = V3.1 */
    uint8_t  reserved1[21];         /* +41 预留 */
    uint16_t crc16;                 /* +62 前 62 字节 CRC-16-CCITT */
} App_Config;

_Static_assert(sizeof(App_Config) == 64, "App_Config must be 64 bytes");
```

3. AT24C08C 物理地址映射

总容量 **1024 字节**（0x0000~0x03FF），仅用于配置双 Bank：

| 起址 | 终址 | 长度 | 区名 | 内容 |
|---|---|---|---|---|
| 0x0000 | 0x003F | 64 B | Bank A 头 | bank 元数据 + CRC |
| 0x0040 | 0x007F | 64 B | Bank A payload | `App_Config` 副本 A |
| 0x0080 | 0x00FF | 128 B | 预留 | 配置增大时使用 |
| 0x0100 | 0x013F | 64 B | Bank B 头 | 同 Bank A 头 |
| 0x0140 | 0x017F | 64 B | Bank B payload | `App_Config` 副本 B |
| 0x0180 | 0x03FF | 640 B | 预留 | 不存放运行日志 |

> 与代码常量对齐（`app_config.h`）：`APP_CONFIG_BANK_A_HDR=0x0000`、`APP_CONFIG_BANK_A_DATA=0x0040`、`APP_CONFIG_BANK_B_HDR=0x0100`、`APP_CONFIG_BANK_B_DATA=0x0140`。

### 3.1 Bank 头结构（64 字节）

| 偏移 | 字段 | 类型 | 含义 |
|---|---|---|---|
| +0 | `bank_magic` | u32 | `0xFAC30001` |
| +4 | `bank_seq` | u32 | 写入序号，启动时选 seq 大者为最新 |
| +8 | `payload_size` | u16 | payload 长度（当前 64） |
| +10 | `payload_offset` | u16 | payload 起始地址（A=0x0040，B=0x0140） |
| +12 | `reserved[50]` | u8×50 | 预留 |
| +62 | `header_crc16` | u16 | 头自身 CRC |

> 用 `bank_seq` 而非时间戳：本机无 RTC，序号等价于"最近修改原则"。

4. 启动加载与写入流程

### 4.1 启动加载（`App_Config_Init`）

```
1. 读 Bank A 头 / Bank B 头，校验 bank_magic + header_crc16 + payload_size
2. 选有效且 bank_seq 最大的 Bank
3. 读 payload，校验 magic(0xFAC3) + CRC16
4. 校验 version == APP_CONFIG_VERSION(2)，不匹配 → 回工厂默认
5. App_Config_Clamp 范围裁剪（越界字段 → 钳到边界 + LOGW）
6. 成功 → s_runtime 生效；两 Bank 均坏（EEPROM 为空/损坏）→ 加载 g_factory_config 兜底，
   并打印 `[W] config: storage not initialized, using factory defaults`
```

### 4.2 写入流程（`App_Config_Save`）

```
1. 目标 Bank = 非当前 active 的那个（A↔B 轮替）
2. Clamp → update_count++ → 算 CRC
3. 写 payload → 读回 memcmp 校验
4. 写 header（bank_seq = 上次 +1）
5. 切换 s_active_bank
```

**断电保护**：任意一步断电，旧 Bank（seq 小者）仍完好，启动时回退。

6. 串口配置命令

所有命令在串口调试模式（发送 `debug` 进入）下使用。

| 命令 | 作用 |
|---|---|
| `cfg dump` | 打印当前 RAM 全部配置（含软硬件版本号） |
| `cfg get`（无参数） | 等价于 `cfg dump`，读取全部 |
| `cfg get <name>` | 读取单个字段 |
| `cfg set <name> <value>` | 修改字段并**立即持久化到 EEPROM**（内存与存储同步） |
| `cfg save` | 兼容命令：显式再写一次 EEPROM（set 已自动落盘，一般无需使用） |
| `cfg load` | 重新从 EEPROM 读取到 RAM |
| `cfg reset` | 恢复出厂设置（**二次确认**，见下） |

`cfg dump` / `cfg get` 输出示例：

```text
[I] ==== config dump ====
[I] fw=FloraMate V1.0  hw=3.1
[I] src=bank_a  update_count=3
[I] n_steps=4  ch_en=0x1F  idle=3s  gap=500ms
[I]   duty[0]=35%  sec[0]=3s
[I]   duty[1]=55%  sec[1]=3s
[I]   duty[2]=75%  sec[2]=3s
[I]   duty[3]=95%  sec[3]=3s
[I] tmo_ch=90s  tmo_all=480s  selftest=50ms
[I] long=1000ms  hold=3000ms  contrast=128  log=2
[I] ==== config dump end ====
```

### 6.1 恢复出厂设置（`cfg reset`，二次确认）

```text
> cfg reset
[W] cfg reset: wipe EEPROM to factory defaults?
[W]   send 'y' to confirm, any other key to cancel

> y
[I] ok: factory reset done (EEPROM wiped to defaults)
```

- 输入 `y` / `yes` → 执行 `App_Config_FactoryReset()`：拷贝 `g_factory_config` 到 RAM 并**连续写两次刷新双 Bank**，EEPROM 中所有参数恢复为代码默认值。
- 输入其它任意内容 → 取消，`[I] cancel: factory reset aborted`，EEPROM 不动。
- 目的：防止误操作直接清空用户已保存的配置。

| C 字段 | 命令行短名 | 范围 |

7. 验收测试要点

| 序 | 测项 | 方法 | 通过判据 |
|---|---|---|---|
| 1 | 首次烧录 | 不预写 EEPROM | 加载工厂默认，`cfg dump` 全为默认值 |
| 2 | 配置保存 | `cfg set duty[0] 40` → `cfg save` → 重启 | 重启后 `duty[0]=40` |
| 3 | 双 Bank 切换 | 连续 `cfg save` 多次 | `update_count` 单调递增 |
| 4 | 断电保护 | 保存中拔电 | 重启加载到旧 Bank |
| 5 | 恢复出厂 | `cfg reset` → `y` | 所有字段回默认，`update_count` 归零 |
| 6 | 恢复出厂取消 | `cfg reset` → 其它键 | EEPROM 不变 |
| 7 | 越界钳位 | `cfg set duty[0] 99` | 读回 95（clamp 到上限） |
