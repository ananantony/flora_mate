```
                                          PWM调速  ───── 开/关 ─────────────────
```

失效安全与控制层级：
  · L0：米家 220V 智能插座（定时通断 12V 适配器，物理总断电）；
  · L1（软件互锁）：水泵 PWM 占空比 > 0 前，须至少一路阀已开（`Bsp_Valve_AnyOn()`），防干转；
  · 复位 / 上电：PA0~PA5 全为 **Low** → 所有 TLP281 截止 → AO4407A 栅极被 10kΩ 上拉到
    +12V → P-MOS 截止 → 全部负载断电（失效安全）。

3. 失效安全与互锁架构 (Fail-Safe & Interlock)

| 项 | 机制 | 失效安全态 |
|---|---|---|
| **上电 / 复位** | MX_GPIO_Init() 把 PA1~PA5 写 Low、TIM2 CCR=0 | 全部 P-MOS 截止，负载断电 ✅ |
| **栅极悬空保护** | 每路 AO4407A 栅极经 10kΩ 上拉到 +12V_DIRTY | 光耦截止时 Vgs=0，强制关断 ✅ |
| **水泵干转保护** | `Bsp_Pump_Pwm_SetDutyPercent()` 非 0 占空比要求 `Bsp_Valve_AnyOn()==true` | 无阀开则拒绝起泵，返回 `FM_ERR_013_PUMP_NO_POWER` |
| **看门狗** | IWDG（生产期开启） | 复位后 GPIO=Low，所有负载断电 ✅ |

> **P 沟道极性铁律（V3.0 高电平有效）**
>
> | MCU GPIO | TLP281 | AO4407A Gate | Vgs | P-MOS | 负载 | 安全？ |
> |---|---|---|---|---|---|---|
> | **Low（复位默认）** | OFF | 经 10kΩ 上拉到 +12V | ≈ 0V | **截止** | 断电 | ✅ 失效安全 |
> | **High（开/起指令）** | ON（拉 Gate→GND_DIRTY） | ≈ 0.3V | ≈ −11.7V | **导通** | 通电 | ✅ 正常 |
>
> 逻辑与 N 沟道版一致（GPIO High = 负载 ON），但**无需 S8050 反相级**，电路更简洁。

6. 子模块详细接线 (Module Wiring)

6.1 固态高边驱动核心（TLP281-4 + AO4407A P-MOS）

**器件选型**：

| 器件 | 型号 | 封装 | 关键参数 |
|---|---|---|---|
| 光耦 | TLP281-4 | SOP-16 | 4 通道独立；LED IF_max=50mA；NPN 输出 Vce_max=80V |
| 功率 MOS | AO4407A | SOIC-8 | **P 沟道**；Vds=−30V；Id=−12A；Rds_on≈8.5mΩ @Vgs=−10V；Vgs(th)≈−1~−3V |

**每路驱动电路（以阀 Z1 / PA1 为例，其余阀同理；泵路仅上拉电阻不同）：**

```
输入侧（ISO_GND 侧）：
  MCU PA1 --[R7=510Ω]-- TLP281_A(LED+)
                         TLP281_K(LED-) -- ISO_GND

输出侧（GND_DIRTY 侧）：
  +12V_DIRTY -- AO4407A_S(源, 1/2/3 脚)
  +12V_DIRTY --[R8=10kΩ]-- AO4407A_G(栅, 4 脚)        ← 栅-源上拉，关断保障
  TLP281_C ───────────────  AO4407A_G(栅, 4 脚)        ← 光耦集电极直接接栅极
  TLP281_E ── GND_DIRTY
  AO4407A_D(漏, 5~8 脚) -- VALVE1_OUT_P -- 阀线圈 -- GND_DIRTY
  续流二极管 1N5822：阴极接 VALVE1_OUT_P，阳极接 GND_DIRTY（贴阀本体安装）
```

**逻辑真值表（失效安全验证）：**

| MCU GPIO | TLP281 | AO4407A_Gate | Vgs | P-MOS | 阀（常闭型） | 安全？ |
|---|---|---|---|---|---|---|
| 0（复位默认） | OFF | 10kΩ 上拉到 +12V | ≈0V | 截止 | 关（无 12V） | ✅ 失效安全 |
| 1（开阀指令） | ON | 拉到 GND_DIRTY | ≈−12V | 导通 | 开（加 12V） | ✅ 正常 |

> **关键设计点**：10kΩ（R8/R9/R13/R14/R15）必须是**栅极↔源极(+12V_DIRTY) 的上拉**，
> 光耦集电极**直接**接栅极。光耦截止时上拉把栅极顶到 +12V（Vgs=0）可靠关断；
> 光耦导通时把栅极拉到 GND_DIRTY（Vgs=−12V）强导通。
> （切勿将该电阻串在"光耦输出—栅极"之间——那样栅极无上拉、关不断，会一直导通。）

6.3 水泵 PWM 调速（AO4407A 高边 + 100 Hz PWM）

水泵与阀**完全相同的高边拓扑**，区别仅在：
  · 由 **PA0 = TIM2_CH1** 输出 **100 Hz PWM**（而非简单开关）驱动 U3-ch1 光耦；
  · 栅极上拉用 **R16 = 4.7kΩ**（比阀的 10kΩ 小，配合栅极电容获得更干净的 PWM 边沿）；
  · 漏极 PUMP_OUT_P 接 12V 隔膜水泵正极，泵负极回 GND_DIRTY。

PWM 极性为**高电平有效**：PA0 高 → 光耦 ON → P-MOS 导通 → 泵加电。
占空比公式 `CCR = ARR × duty% = 999 × duty%`，初始 CCR=0（上电停泵）。
**干转保护**：占空比非 0 前软件强制至少一路阀已开（见 § 3）。

6.4 阀门状态指示灯（可选）

每路设指示 LED：`+12V_DIRTY --[4.7kΩ]-- LED -- VALVEx_OUT_P`。
  · P-MOS 截止（阀关，OUT_P≈0V）→ LED 两端约 12V → **LED 亮 = 阀关**；
  · P-MOS 导通（阀开，OUT_P≈12V）→ LED 两端≈0V → **LED 灭 = 阀开**。

> 注意：该指示逻辑与"通电发光"直觉相反，调试时以 OUT_P 实测电压或栅极电压为准。

6.5 SSD1315 OLED + 4 按键模块

  · OLED：I²C 地址 0x3C，接 PB6/PB7（与 EEPROM 共用 I²C1，模块板自带上拉）。
  · 按键 K1~K4：PA6/PA7/PB0/PB1，**内部上拉**，按下接 ISO_GND（低电平有效），
    软件 20 ms 轮询去抖。

6.6 AT24C08C 配置存储

| 项 | 参数 |
|---|---|
| 容量 | **1 KB**（1024 B），内部 10-bit 地址，分 4 个 256 B 块 |
| 页大小 | **16 B**（写边界） |
| 7-bit 基地址 | **0x50**（E0/E1/E2 全接 GND） |
| 块寻址 | 设备地址 = `0x50` 按位或 `(((addr>>8)&0x03)<<1)`；片内字节地址 = `addr & 0xFF`（8-bit） |
| 写保护 | WCB（WP）接 **3V3**（开发期允许写入） |
| 接口 | I²C1 Fast 400 kHz，与 OLED 共用 PB6/PB7 |

6.7 板载心跳 LED（PC13）

板载红色 LED D3，**低电平点亮**；上电先灭（PC13 初始 High），固件每 500 ms 翻转一次。

7. 供电分配网络 V3.0 (PDN)

```
12V/4A 适配器 (经 L0 米家插座)
    │
    ├─ NTC 5D-9（浪涌限流）
    ├─ 自恢复保险 1812L300 (3A)
    ├─ 470µF/25V + 1µF 陶瓷（入口储能/去耦）
    ├─ SMBJ15CA TVS（双向，12V 入口浪涌钳位）
    │
    └─> +12V_DIRTY 总母线
            │
            ├─> 6×AO4407A 源极（高边开关功率路径）
            ├─> 各路栅极上拉电阻（R8/9/13/14/15=10k，R16=4.7k；µA 级取电）
            ├─> 阀门指示 LED 支路（4.7kΩ 限流）
            │
            └─> 隔离 DC-DC 12V→5V_ISO
                    └─> 核心板 5V → AMS1117 → 3.3V (ISO_GND)
                              MCU / OLED / EEPROM / TLP281 LED 侧
```

> **双地隔离**：MCU 侧 **ISO_GND** 与功率侧 **GND_DIRTY** 通过隔离 DC-DC 与 TLP281
> 光学隔离彻底分开，泵/阀的开关噪声不串入 MCU 与 I²C 总线。

8. 续流、保护与浪涌抑制 V3.0 (Protection Stack)

| 位置 | 元件 | 规格 | 作用 |
|---|---|---|---|
| 阀线圈两端 | 1N5822 (3A/40V) | 反向并联（阴极→OUT_P，阳极→GND_DIRTY），贴阀本体 | 关断瞬间续流 |
| 水泵两端 | SS54 (5A/40V) | 反向并联（阴极→PUMP_OUT_P，阳极→GND_DIRTY），贴泵端 | 堵转/关断续流 |
| AO4407A 栅-源极 | （可选）BZX84C12 12V 稳压管 | 栅极钳位 | 防 Vgs 绝对值过压击穿（>20V） |
| 12V 入口 | SMBJ15CA + 470µF + NTC 5D-9 | 浪涌三件套 | 浪涌吸收/限流 |
| MCU VDD | 0.1µF + 4.7µF MLCC | 紧贴芯片 | VDD 去耦 |

> P 沟道高边为软开关，无机械触点电弧，**无需 RC 灭弧网络**。

9. 线束与施工工艺 (Wiring SOP)

  · 室内主机 → 室外阀岛：多芯线缆，含 **5 路阀+ (VALVEx_OUT_P)** 与 **1 路 GND_DIRTY 公共回流**；
  · 阀+ 与 GND 截面 ≥ 0.5 mm²；续流二极管贴阀本体就近安装；
  · 12V 主干（适配器→母线→泵）用 18~20 AWG；信号/控制线 24 AWG；
  · ISO_GND 与 GND_DIRTY **严禁短接**（破坏隔离）。

12. 与 V2.0（N 沟道版）的差异说明

| 章节 | V2.0（N-MOS + S8050） | V3.0（P-MOS 高边） | 影响 |
|---|---|---|---|
| 功率管 | AO3400 N 沟道 ×7 | **AO4407A P 沟道 ×6** | 高边开关，少 1 路 |
| 反相级 | S8050 NPN ×7 | **取消** | 电路简化、元件减少 |
| 栅极驱动 | 12V→S8050→栅极，栅极下拉 100k | **光耦直拉栅极 + 10k 上拉到 +12V** | 逻辑同为 High=ON |
| 水泵 | PUMP_EN(PB1) + LR7843 模块 | **AO4407A 高边 + PA0 直接 PWM** | 去掉 PUMP_EN 与 LR7843 |
| 干转保护 | 硬件 PUMP_EN + 软件互锁 | **纯软件互锁 `Bsp_Valve_AnyOn()`** | 简化硬件 |
| 阀引脚 | PB12~PB15 + PA8 | **PA1~PA5（连续）** | 重排 |
| 泵 PWM 引脚 | PA0 | PA0 | 不变 |
| 按键引脚 | PA1~PA4 | **PA6/PA7/PB0/PB1** | 重排 |
| EEPROM | AT24C64 | **AT24C08C（1KB）** | 容量调整 |
| 软件 BSP | `bsp_relay`/含 PUMP_EN | `bsp_valve`（Z1~Z5）+ `bsp_pump_pwm` | 已重构 |

13. 验收测试要点 V3.0 (Acceptance Tests)

| 序 | 测项 | 方法 | 通过判据 |
|---|---|---|---|
| 1 | 双地隔离 | 万用表蜂鸣档测 GND_DIRTY ↔ ISO_GND | **不通**（断路） |
| 2 | 3.3V 电压 | 核心板 3V3 排针 | 3.30V ±0.05V |
| 3 | TLP281 LED 电流 | 测 510Ω 输入串阻两端电压（GPIO 拉高时） | ~1.2V（IF≈2.3mA）量级，光耦可靠导通 |
| 4 | 阀 P-MOS 截止（默认） | 上电不开阀，测栅极电压 | 栅极 ≈ +12V（Vgs≈0，截止） |
| 5 | 阀 P-MOS 导通 | 固件逐路开阀，测栅极 + OUT_P | 栅极 ≈ 0V；OUT_P ≈ 12V（带负载） |
| 6 | 干转互锁 | 不开任何阀直接给泵占空比 | 串口报 `FM_ERR_013_PUMP_NO_POWER` |
| 7 | 水泵 PWM | 先开阀再给占空比，示波器测 PA0 / PUMP_OUT_P | 100 Hz ±5%，0~95% 线性可调 |
| 8 | 看门狗复位 | 故意停喂狗 | MCU 复位，GPIO=Low，所有负载断电 |
| 9 | I²C 扫描 | i2cdetect | 检测到 0x3C(OLED) 与 0x50(EEPROM) |
| 10 | 按键 4 路 | 串口 key test | K1~K4 翻转无串扰 |

> 调试提示：阀/泵关断时若 OUT_P 端**空载**，万用表会因漏极悬空读到接近 12V 的"幻象电压"，
> 属正常测量假象；应**接上负载**或改测**栅极电压**判断 P-MOS 真实通断。
