# FloraMate 屏幕与按键交互设计 V2.0

> 产品侧 HMI 设计说明（**V2.0 已实现并手测通过**）。  
> 已替换《上电运行分支与操作逻辑 V1.1》中的「Boot Wait 10s + K1+K2 进手动」路径，改为 **Logo → Idle → 主界面 / 自动浇水**。  
> 串口调试保留；常规入口为「设置 → 串口测试」，Idle 期间仍可直接发 `debug`（产线便利）。

| 项目 | 内容 |
|------|------|
| 文档版本 | V2.0.2（已实现） |
| 日期 | 2026-09-10 |
| 依据 | 本次口述需求；现有 `app_menu` / `app_main_fsm` / `app_config`；Top 板 4 键 + 1.3" 128×64 OLED |
| 不包含 | 字模点阵、串口命令字（串口命令仍见既有说明） |

## 0. 设计要点

四键语义清晰，页面分层：开机门槛（Idle）→ 主界面（浇水 / 设置）→ 设置（参数 / 本地测试 / 串口）。相比旧版「上电 10 秒等待 + 组合键进手动」，更符合产品使用场景。

下列条目已在 **§8 确认结论** 中拍板，并按本文实现于 `App/main_fsm`、`App/menu`、`App/display`。

### 0.1 建议采纳（强烈）

| # | 问题 | 建议 |
|---|------|------|
| A | Idle 要 **K1+K3 同时长按 2s** 才进主界面 | **保留。** 这是防误触门槛：上电放着不管会自动浇水，不会因为碰一下按键就进菜单。与旧版 K1+K2 组合同思路，只是改成 K1+K3，避免和「上/下」语义打架。 |
| B | 自动浇水过程中没有退出键 | **增加 K4 = 紧急停止**：立即停泵关阀，进入「已停止」页，再按 K4 回主界面。否则泵会一直跑到流程结束。 |
| C | 参数改完没说何时写 EEPROM | **单项确认才保存。** 光标选中 → K3 进入编辑 → K1/K2 加减 → **K3 写入 EEPROM**；**K4 放弃本次编辑**。离开参数列表时不再偷偷整表保存，避免误触改坏配置。 |
| D | 供水测试离开页面 | **离开本页（K4）或进其它测试页时，全部阀关闭、泵 0%。** 这是 Fail-Safe，必须写死。 |
| E | 上电是否还做阀自检短脉冲 | **产品路径不做。** 每次上电嘀嗒五路阀会吓到用户、也浪费水。自检放到本地测试 / 工厂流程。Idle 超时后按 EEPROM 配置直接浇水。 |
| F | Idle 5s 与配置项 `idle_seconds`（现默认 3s） | **Idle 倒计时固定 5s**（本设计常量），不再复用浇灌配置里的 `idle_seconds`，避免改参数把开机门槛一起改掉。 |

### 0.2 建议采纳（体验 / 安全）

| # | 问题 | 建议 |
|---|------|------|
| G | Logo「读取失败」一闪而过 | Logo **至少停留 2s**。若 EEPROM 失败，在版本行显示失败文案，**再额外停留 2s**（合计约 4s），然后仍进 Idle，并加载出厂默认。 |
| H | 浇水完成后一直等 K4 | **已确认：一直等 K4**，完成页不超时。 |
| I | 泵百分比步长 / 上限 | 步长 **5%**，范围 **0~95%**（与现有 PWM 安全上限一致）。未进入泵编辑时，K3 只是选中该项，不立刻改占空比。 |
| J | 供水测试五路阀是否互锁 | 按你的需求：**允许同时开多路**（方便查继电器）。但屏幕上要能看见每一路 ON/OFF。若以后漏水风险大，再加「同时只开一路」。 |
| K | 通道使能 `ch_en` 用加减很别扭 | 参数页里该项 **K3 进入后，K1/K2 在 Z1~Z5 之间选通道，K3 翻转该路使能**，而不是对 0x1F 做 ±1。 |

### 0.3 OLED 文案语言（已确认）

**本期采用英文短词 + 数字编号。** 例如 `1.Auto Water` / `2.Settings`。页面底行固定 `K1v K2^ K3OK K4Esc`。中文字库以后再做，只换字符串即可。

### 0.4 版本号显示（已确认）

**读取成功显示真实版本；仅读取失败才显示 0.0。** 已有 EEPROM 双 Bank 读取能力，不改 Flash/出厂默认值去强行写成 0.0。

| 条件 | SW | HW | 附加 |
|------|----|----|------|
| EEPROM 配置读取成功 | Flash 常量（如 `V1.0`） | EEPROM `hw_version` BCD（如 `3.1`） | — |
| 读取失败（回落工厂默认） | `0.0` | `0.0` | `CFG LOAD FAIL` |

### 0.5 与旧逻辑的关系（已实现）

| 旧行为（V1.1） | 本期 |
|----------------|------|
| 上电 Boot Wait 10s | Logo 2s → Idle 5s |
| K1+K2 2.5s 进手动选择 | Idle 里 K1+K3 2s 进主界面 |
| 等待窗发 `debug` 进串口 | 设置 → 串口测试；**Idle 期间仍可收 `debug` 进串口**（方便产线，见 §6.2） |
| 阀自检短脉冲在 BOOT | 产品路径跳过 |
| 主菜单 6 项（含出厂复位/休眠） | 主界面仅 2 项；出厂复位本期不做（可后续加在参数页） |

## 1. 按键总则

硬件：K1~K4，按下为低电平，软件消抖后产生短按 / 长按 / 组合键。

### 1.1 默认映射（所有菜单列表页）

| 按键 | 默认语义 |
|------|----------|
| **K1** | 光标 **下**；编辑数值时 **增加** |
| **K2** | 光标 **上**；编辑数值时 **减少** |
| **K3** | **Enter**：进入子页 / 选中 / 继电器翻转 / 确认保存 |
| **K4** | **退出**：返回上一级；必要时先关输出 |

例外以 **该页屏幕提示为准**（见各页「按键」表）。未写到的长按，一律当短按忽略，避免误触发。

### 1.2 组合键（仅 Idle）

| 操作 | 条件 | 效果 |
|------|------|------|
| K1+K3 长按 | 两键同时按下并保持 **≥ 2000 ms** | 取消 5s 倒计时，进入 **主界面** |
| 只按 K1 或只按 K3 | 不满足组合 | **不**进入主界面，倒计时继续 |
| K2 / K4 | Idle 期间 | 无动作（可在底行提示，避免用户乱按） |

松手再按，计时清零重来。

### 1.3 输入规则

- 光标循环：到最后一项再按 K1 → 回到第一项；到第一项再按 K2 → 跳到最后一项。
- 数值加减到边界后 **夹紧，不溢出、不回绕**（泵 0~95，时间类走配置表 min/max）。
- 任何会驱动阀/泵的页面，**进入时输出全关**；**退出时输出全关**。

## 2. 页面树

```
上电
 └─ P0 Logo（读 EEPROM，≥2s）
     └─ P1 Idle（5s 倒计时）
         ├─ 超时 ──────────────────────────────► P2 自动浇水 ─► P3 完成
         ├─ K1+K3 按住 2s ─────────────────────► P4 主界面
         └─ 串口 debug（产线保留）─────────────► P8 串口测试
                                                  │
P4 主界面                                         │
 ├─ 1 自动浇水 ──► P2 ──► P3（K4 回 P4）          │
 └─ 2 设置与参数 ──► P5 设置                      │
                      ├─ 1 参数 ──► P6            │
                      ├─ 2 本地测试 ──► P7        │
                      │    ├─ 屏幕测试            │
                      │    ├─ 按键测试            │
                      │    └─ 供水测试            │
                      └─ 3 串口测试 ──► P8 ◄──────┘
```

**Idle 只在每次上电走一次。** 从完成页、设置、测试回到的都是 **主界面 P4**，不会再自动浇水，除非用户在主界面再选「自动浇水」。

## 3. 主状态（替换现有上电 FSM 产品路径）

```
POWER_ON → LOGO → IDLE
                    ├─ (timeout) → AUTO_RUN → DONE ──K4──► MENU_MAIN
                    ├─ (K1+K3 2s) → MENU_MAIN
                    └─ (debug) → SERIAL_TEST ──退出──► MENU_MAIN
MENU_MAIN
  ├─ Auto Water → AUTO_RUN → DONE ──K4──► MENU_MAIN
  └─ Settings → MENU_SET → (Params / LocalTest / Serial)
ERROR：任意致命故障 → 全关输出 → 错误页（K4 回主界面；主界面进不去则停在错误页）
```

自动浇水内部仍复用现有 `app_pump_fsm`（按 `channel_enable`、阶梯 PWM、路间间隔）。本期只改 **谁在何时触发它**，以及屏幕/按键。

## 4. 各页面说明

屏幕约定（英文方案）：

- 第 0 行：反白标题  
- 第 1 行：分隔或状态  
- 第 2~5 行：正文 / 列表（可见约 4 项，超出滚动）  
- 第 7 行：本页按键提示  

### 4.1 P0 Logo

**进入：** 上电，OLED 初始化成功后立即显示。  
**并行：** 底层读 EEPROM（双 Bank + CRC）。读完再更新版本行，**不要等读完才画 Logo**。

显示：

```
+------------------+
|    FloraMate     |
|                  |
|    SW 0.0        |
|    HW 0.0        |
|                  |
|  (可选进度点)    |
+------------------+
```

| 条件 | 版本行 | 停留 |
|------|--------|------|
| 读取成功 | `SW x.y`（Flash） / `HW x.y`（EEPROM） | 自显示起 **满 2s** 再进 Idle |
| 读取失败 | `SW 0.0` / `HW 0.0` + `CFG LOAD FAIL`；加载工厂默认 | 失败文案出现后再 **满 2s** 进 Idle |
| OLED 失败 | 屏幕无内容，串口打日志 | 仍走同一套超时，不卡死 |

本页 **不响应按键**。

### 4.2 P1 Idle

显示：

```
+------------------+
|      IDLE        |
|  Auto in 5s      |
|                  |
| Hold K1+K3 2s    |
|  -> Main Menu    |
|                  |
| K1+K3: Menu      |
+------------------+
```

- `Auto in Ns` 每秒更新，N = 剩余秒（5…1）。  
- 组合键按住期间：倒计时 **冻结**，显示按住进度（如 `Hold 50%`）。松开且未满 2s：进度清零，倒计时继续。

| 按键 | 动作 |
|------|------|
| K1+K3 ≥2s | → 主界面 |
| 其它单键 | 忽略 |
| 超时 | → 自动浇水（用当前 RAM 配置，即 EEPROM 或默认） |

### 4.3 P2 自动浇水

显示当前路、泵占空比、已进行时间（复用现有 RUN 页信息即可）。

| 按键 | 动作 |
|------|------|
| K4 | **紧急停止**：全关 → P3 文案改为 `STOPPED`（或中文「已停止」） |
| K1/K2/K3 | 忽略（避免误触跳路） |

流程正常结束 → P3 `DONE`。

### 4.4 P3 完成 / 停止

```
+------------------+
|      DONE        |
|  Watering OK     |   ← 若 K4 中止则为 Stopped
|                  |
|  K4: Main Menu   |
+------------------+
```

| 按键 | 动作 |
|------|------|
| K4 | → 主界面 |
| 其它 | 忽略 |

输出保持全关。本页 **无超时**，一直等 K4。

### 4.5 P4 主界面

```
+------------------+
|      MAIN        |
| > 1.Auto Water   |
|   2.Settings     |
|                  |
|                  |
| K1v K2^ K3OK     |
+------------------+
```

| 按键 | 动作 |
|------|------|
| K1 / K2 | 两项间移动 |
| K3 | 光标 1 → P2；光标 2 → P5 |
| K4 | **无上一级**，忽略（或以后用于关机提示；本期忽略） |

### 4.6 P5 设置

```
+------------------+
|    SETTINGS      |
| > 1.Params       |
|   2.Local Test   |
|   3.Serial Test  |
|                  |
| K1v K2^ K3OK K4  |
+------------------+
```

| 按键 | 动作 |
|------|------|
| K1 / K2 | 移动 |
| K3 | 进入对应子页 |
| K4 | 回主界面 |

### 4.7 P6 参数

列表滚动显示可调参数（与 `App_Config` 用户字段对齐，**不含** magic/crc/`hw_version`）。

建议可见项（可滚动）：

| 显示名 | 字段 | 编辑方式 |
|--------|------|----------|
| n_steps | 阶梯档数 | ±1 |
| duty0..3 | 各档占空比 % | ±5 |
| sec0..3 | 各档秒 | ±1 |
| ch_en | 五路使能 | 见 §0.2 K |
| gap_ms | 路间隔 | 按现有步长 |
| tmo_ch / tmo_all | 超时 | 按现有步长 |
| contrast | OLED 对比度 | ±8，**即时生效**，K3 才落盘 |
| long_ms | 长按门限 | 一般用户可不放第一屏；本期仍列出 |

**交互：**

1. 浏览：K1/K2 移动，当前行反白，右侧显示现值。  
2. K3：进入编辑（该行闪烁或左侧 `*`）。  
3. 编辑中 K1/K2：改 **RAM 草稿**，未写 EEPROM。  
4. 编辑中 K3：Clamp → 写入 EEPROM → 退出编辑。  
5. 编辑中 K4：丢弃草稿，显示原值，回到浏览。  
6. 浏览时 K4：回设置页。

对比度在编辑过程中可立刻 `SetContrast`，K4 放弃则恢复已保存值。

### 4.8 P7 本地测试（子菜单）

```
+------------------+
|   LOCAL TEST     |
| > 1.Screen       |
|   2.Key          |
|   3.Water        |
|                  |
| K3OK  K4 Back    |
+------------------+
```

K4 回设置。进入任一子测试前保证输出全关。

#### 4.8.1 屏幕测试

目的：看是否有坏点、镜像、偏页（SH1106）。

自动循环（每项约 800ms，可按 K3 手动下一项）：

1. 全白  
2. 全黑  
3. 棋盘  
4. 横条  
5. 竖条  
6. 边框 + `SCREEN TEST`

| 按键 | 动作 |
|------|------|
| K4 | 立即回本地测试菜单 |
| K3 | 下一项图案（可选） |
| K1/K2 | 忽略 |

#### 4.8.2 按键测试

四行实时状态：按下反白 `K1 ON`，松开 `K1 --`（可沿用现有 key test 页）。

| 按键 | 动作 |
|------|------|
| 任一键按下/松开 | 刷新显示，**无操作计时清零** |
| **连续 5s 无任何键边沿** | 自动回本地测试菜单 |

本页 K4 **不立刻退出**（否则无法测 K4）。退出只靠 5s 超时。  
底行提示：`Idle 5s = Back`。

#### 4.8.3 供水测试

光标 6 项：`Z1` `Z2` `Z3` `Z4` `Z5` `PUMP %`。  
每项显示当前状态：阀 `ON`/`OFF`，泵 `nn%`。

| 焦点 | K3 | K1 / K2 | K4 |
|------|----|---------|-----|
| Z1~Z5 | 翻转该路开/关 | 移动光标 | 全关并回本地测试 |
| PUMP（未编辑） | **进入编辑**（泵项闪烁） | 移动光标 | 全关并返回 |
| PUMP（编辑中） | 退出编辑（保持当前占空比） | ±5%，夹紧 0~95 | 退出编辑，**泵立刻 0%**，仍留在本页 |

说明：

- 阀与泵无软件互锁（按你的需求）。  
- 查询即屏幕上的 ON/OFF 与百分比，与 GPIO/PWM 寄存器一致。  
- 进入本页时泵 = 0%，阀全关。

### 4.9 P8 串口测试

进入后行为对齐现有 `SERIAL_DEBUG`：USART1 命令行可用（`valve` / `pump` / `cfg` 等）。

OLED：

```
+------------------+
|  SERIAL TEST     |
|  115200 8N1      |
|  wait UART...    |
|                  |
| Hold K4 2s: Back |
+------------------+
```

| 按键 | 动作 |
|------|------|
| K4 按住 2s | 关输出，退出到 **设置页**（若从 Idle 的 `debug` 进来，则到 **主界面**） |
| 其它键 | 不抢命令行（与旧版一致） |

Idle 窗口内若收到 `debug`/`dbg`：直接进本页，**取消自动浇水倒计时**。这是给产线留的后门，屏幕可加一行 `UART debug`。

## 5. 超时与常量（草案）

| 名称 | 值 | 说明 |
|------|----|------|
| Logo 最短显示 | 2000 ms | 读 EEPROM 通常远小于此 |
| Logo 失败附加 | 2000 ms | 让用户看见失败 |
| Idle 自动浇水 | 5000 ms | 仅上电 Idle |
| 进主界面组合 | K1+K3 同时 ≥ 2000 ms | |
| 按键测试无操作返回 | 5000 ms | 无边沿才算无操作 |
| 屏幕测试单项 | 800 ms | |
| 泵步进 | 5% | |
| 泵上限 | 95% | |
| 串口退出 | K4 ≥ 2000 ms | |

长按门限配置项 `long_ms` **不覆盖** 上述 2s 组合键，避免用户把长按改成 300ms 后无法进菜单。

## 6. 安全与失败

1. 上电 GPIO 默认全关（已有）。  
2. 进入/离开任何测试页、完成页、紧急停止：阀全关、泵 0%。  
3. EEPROM 失败：默认配置继续工作，Logo 提示失败，不砖机。  
4. OLED 失败：状态机照跑，依赖串口日志。  
5. AUTO_RUN 总超时 / 单路超时：沿用现有 ERROR 处理，屏幕显示错误码，K4 尝试回主界面（输出保持关）。
