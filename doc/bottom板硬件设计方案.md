本文件覆盖：

## 2. 系统架构与定位 (Architecture & Position)

```
                    ┌──────────────── top 板（控制板）────────────────┐
                    │  STM32F401RCT6 + OLED + EEPROM + CH340C + USB    │
                    │  3V3/ISO_GND 域 · 控制命令 GPIO · I2C2 总线       │
                    └──────────────────────┬──────────────────────────┘
                                           │ 20P 排针 H1
                                           │ (+5V_CLEAN×2 / ISO_GND×8 /
                                           │  PUMP_CMD / VALVE1~5_CMD /
                                           │  I2C2_SCL / I2C2_SDA)
                    ┌──────────────────────▼──────────────────────────┐
                    │ ┌─────────────┐   ┌──────────────────────────┐  │
                    │ │ 12V 输入保护  │──▶│ 隔离DC-DC 12V→5V_ISO     │  │
                    │ │ F1/D6/C3... │   │ └→ π滤波 → +5V_CLEAN(ISO) │  │
                    │ └──────┬──────┘   └──────────────────────────┘  │
                    │        │ 12V_AUX                                   │
                    │   ┌────┴─────────────────────┐                   │
                    │   │ 6×AO4407A 高边开关        │                   │
                    │   │ (泵 PWM + 阀 Z1~Z5)       │                   │
                    │   └────┬───────────────────┬─┘                   │
                    │        │ 12V_PUMP          │ 12V_VALVE            │
                    │   INA226 U11(0x40)    INA226 U3(0x41)             │
                    │        └────────┬──────────┘                     │
                    │            ISO1540 I2C 隔离桥 (U6)                │
                    │  ┌────── 3V3 本地电源（PGND 域）──────┐           │
                    └──┴───────────────────────────────────┴───────────┘
                              │
                         泵 / 电磁阀 / 端子台
```

**双板分工**：top 板负责"大脑"（MCU、HMI、存储、USB 调试）；bottom 板负责"动力"（电源变换、功率开关、电流检测）。强弱电信号仅经光耦（TLP281-4）与隔离 I2C（ISO1540）跨域传递。

**地结构（三类地）**：

| 地 | 范围 | 用途 |
|---|---|---|
| **PGND** | 12V 入口、隔离 DC-DC 输入侧、AO4407A、泵/阀回路、INA226、3V3 LDO、ISO1540 次级 | 功率地（"脏"地） |
| **ISO_GND** | 隔离 DC-DC 输出侧、+5V_CLEAN、ISO1540 初级、假负载 | 隔离净地，经 H1 供 top 板 |
| （top 板内） | AMS1117-3.3 输出 | MCU 数字地（ISO_GND 域延续） |

> 功率侧电流检测（INA226）工作在 PGND 域，其 I2C 经 ISO1540 隔离后上行到 top 板，检测数据跨域无干扰。

## 3. 电源系统 (Power System)

### 3.1 12V 输入保护与功率母线

```
POWER_IN(+12v / PGND)
    │
    ├─ F1  自恢复保险丝（PPTC，按泵最大电流留 1.3 倍余量，建议 2.5~3A）
    ├─ D6  TVS 瞬态抑制（SMBJ15CA 类，双向，12V 入口钳位）
    ├─ C1  100nF 陶瓷（高频去耦）
    ├─ C2  1µF 陶瓷
    ├─ C3  470µF/25V 电解（入口储能/浪涌缓冲）
    ├─ C7  10µF 陶瓷（母线滤波）
    ├─ C13 10µF / C14 100nF（U8 输入侧旁路）
    │
    └─> 12V_AUX 功率母线
           ├─ 隔离 DC-DC U8（→ 5V_ISO）
           ├─ 6×AO4407A 源极（泵/阀功率路径）
           ├─ 6×栅极上拉电阻（4.7k×1 / 10k×5）
           ├─ U14 3V3 LDO
           ├─ R3-LED1 电源指示（12V_AUX → 4.7k → LED1 → PGND）
           └─ 10mΩ 采样电阻 U1/U12 上游
```

### 3.2 隔离 5V 供电链（ISO_GND 域）

```
12V_AUX ──> U8 隔离 DC-DC（B1205XT-1WR3，12V→5V，1W）
               │ Vout+  ──> $5N49
               │ Vout-  ──> ISO_GND
               ▼
      π 型滤波：C9(10µF) ── L1(10µH) ── C10(47µF)
               ▼
        +5V_CLEAN（隔离净电）
           ├─ R11 470Ω 假负载（→ISO_GND，约 10.6mA，保证隔离模块 ≥10% 最小负载稳定稳压）
           ├─ C4 100nF（去耦）
           ├─ ISO1540 VCC1（U6）
           └─ H1.Pin1/Pin2 → top 板（经 AMS1117-3.3 供 MCU/OLED/EEPROM/CH340C）
```

**功率核算（B1205XT-1WR3，5V/200mA）**：

| 负载 | 电流 |
|---|---|
| R11 假负载 | ~10.6mA |
| ISO1540 初级 + 上拉 | ~2mA |
| top 板 AMS1117-3.3 输入 | ~85~105mA |
| **合计** | **~100~120mA（≈60% 额定）** |

余量约 40%。插 USB 调试时 top 板 5V_MAIN 由 5V_USB 直供，反而减轻隔离模块负担。当前 1W 方案可行；后续若加 WiFi/继电器等大负载再升级 2W（B1205S-2WR3）。

### 3.3 3V3 本地电源（PGND 域）

```
12V_AUX ──> U14（AMS1117-3.3）──> 3V3（PGND 域）
              │                     ├─ C16 10µF + C15 100nF（输出滤波）
              └─ C13/C14 输入旁路   ├─ ISO1540 VCC2（U6）
                                    ├─ INA226 VS（U11/U3）
                                    └─ I2C 上拉 R7/R8（4.7kΩ → 3V3）
```

> 该 3V3 专供**功率侧检测电路**（ISO1540 次级 + INA226×2 + I2C 上拉），负载约 12mA，AMS1117 压差 8.7V，损耗 ≈0.1W，可接受。
> 因次级侧必须位于 PGND 域（与 +5V_CLEAN 的 ISO_GND 隔离），故不能从 5V_CLEAN 取电，只能由 12V_AUX 直接降压。

## 4. 高边驱动（6×AO4407A + 2×TLP281-4）

### 4.1 器件选型

| 器件 | 型号 | 封装 | 关键参数 |
|---|---|---|---|
| 光耦 | TLP281-4 | SOP-16 | 4 通道独立；LED IF_max=50mA；NPN 输出 Vce_max=80V；CTR≥50% |
| 功率 MOS | AO4407A | SOIC-8 | **P 沟道**；Vds=−30V；Id=−12A；Rds_on≈8.5mΩ @Vgs=−10V；Vgs(th)≈−1~−3V |

### 4.2 通道映射（U15/U16）

TLP281-4 引脚规律：`AN1/2/3/4 = Pin1/3/5/7`，对应输出 `COL1/2/3/4 = Pin16/14/12/10`，`EM = Pin15/13/11/9`。

| IC | 通道 | 输入（LED 侧） | 输出（光敏管侧） | 负载 MOS | 栅极上拉 |
|---|---|---|---|---|---|
| **U15** | ch1 | PUMP_CMD → R18(510Ω) → AN1 | COL1 → PUMP_GATE | U13（泵） | **R12 = 4.7kΩ → 12V_PUMP** |
| U15 | ch2 | VALVE1_CMD → R19(510Ω) → AN2 | COL2 → VALVE1_GATE | U9 | R9 = 10kΩ → 12V_VALVE |
| U15 | ch3 | VALVE2_CMD → R20(510Ω) → AN3 | COL3 → VALVE2_GATE | U2 | R1 = 10kΩ → 12V_VALVE |
| U15 | ch4 | VALVE3_CMD → R21(510Ω) → AN4 | COL4 → VALVE3_GATE | U4 | R2 = 10kΩ → 12V_VALVE |
| **U16** | ch1 | VALVE4_CMD → R22(510Ω) → AN1 | COL1 → VALVE4_GATE | U7 | R6 = 10kΩ → 12V_VALVE |
| U16 | ch2 | VALVE5_CMD → R23(510Ω) → AN2 | COL2 → VALVE5_GATE | U10 | R10 = 10kΩ → 12V_VALVE |
| U16 | ch3/ch4 | 空置 | 空置（无网络） | -- | -- |

> 已核对：每路 CMD 从哪个通道 AN 进入，即从同通道 COL 输出，**通道配对正确**。

### 4.3 驱动拓扑（每路一致，以阀 Z1 为例）

```
输入侧（ISO_GND 域）：
  H1(VALVE1_CMD) ── R19 510Ω ── TLP281 AN2 ──┐
                                            └── LED- → ISO_GND
输出侧（PGND 域）：
  +12V_VALVE ── AO4407A_S(1/2/3脚)
  +12V_VALVE ── R9 10kΩ ── AO4407A_G(4脚)     ← 栅-源上拉，关断保障
  TLP281 COL2 ──────────── AO4407A_G(4脚)     ← 光耦集电极直拉栅极
  TLP281 EM2 ── PGND
  AO4407A_D(5~8脚) ── VALVE1_OUT_P ── 阀线圈 ── PGND
  D1 续流二极管：阴极→VALVE1_OUT_P，阳极→PGND
  LED3 ── R16 4.7kΩ：VALVE1_OUT_P → PGND（MOS 导通时点亮 = 阀开指示）
```

**真值表（失效安全）**：

| MCU GPIO | TLP281 | AO4407A Gate | Vgs | P-MOS | 负载 |
|---|---|---|---|---|---|
| Low（复位默认） | OFF | 上拉至 12V | ≈0V | **截止** | 断电 ✅ |
| High | ON | 拉至 PGND | ≈−12V | 导通 | 通电 |

### 4.4 栅极上拉电阻差异化（泵 4.7k / 阀 10k）

| 负载 | 上拉 | 依据 |
|---|---|---|
| 水泵 | **4.7kΩ** | 泵需 PWM 调速，开关沿更快，抑制开关损耗与温升 |
| 电磁阀 | **10kΩ** | 阀长时间吸合（静态），降低栅极回路静态损耗，提高光耦饱和裕量 |

> 两者均为有效设计，无需统一。泵/阀的开启时间常数（Rg×Ciss）差异不敏感于 PWM=100Hz 应用。

## 5. 电流 / 功率检测（INA226 ×2）

### 5.1 检测拓扑

```
泵路：  12V_AUX ── U12(10mΩ 采样) ── 12V_PUMP ── U13(AO4407A) ── 泵
         IN+/IN- 跨接 U12 两端（R14 10Ω + C11 100nF RC 滤波）
         VBUS = 12V_PUMP（检测泵供电母线）→ 功率 = V × I

阀路：  12V_AUX ── U1(10mΩ 采样) ── 12V_VALVE ── U9/U2/U4/U7/U10(5×AO4407A) ── 阀
         IN+/IN- 跨接 U1 两端（R4/R5 10Ω + C5 100nF RC 滤波）
         VBUS = 12V_VALVE → 阀总功率
```

### 5.2 INA226 配置

| IC | 采样电阻 | VBUS | 地址（A1:A0） | 用途 |
|---|---|---|---|---|
| **U11** | U12 = 10mΩ（泵路） | 12V_PUMP | A1=0, A0=0 → **0x40** | 泵电流/功率 |
| **U3** | U1 = 10mΩ（阀路） | 12V_VALVE | A1=0, A0=1 → **0x41** | 阀总电流/功率 |

| 引脚 | 连接 |
|---|---|
| VS | 3V3 |
| GND | PGND |
| SCL/SDA | ISO1540 次级（SCL/SDA） |
| ALERT | 未用（悬空） |

> 10mΩ / 满量程 ±81.92mV → 最大量程 ±8.192A，覆盖泵（~1.5A）与阀（~0.15A）测量范围；1LSB=2.5µV → 电流分辨率 0.25mA。

## 6. I2C 隔离桥（ISO1540，U6）

```
top 板 STM32 I2C2 (3V3/ISO_GND 域, 已上拉 4.7k)
    │
H1 ── I2C2_SCL ──> U6.SCL1 (Pin2)
      I2C2_SDA ──> U6.SDA1 (Pin3)
    │
U6：VCC1 = +5V_CLEAN（Pin3），GND1 = ISO_GND（Pin4）
    VCC2 = 3V3（Pin6），GND2 = PGND（Pin5）
    │
次级：SCL2(Pin8) / SDA2(Pin7) ── INA226 U11(0x40) / U3(0x41)
      上拉 R8/R7 = 4.7kΩ → 3V3
```

| 参数 | 值 |
|---|---|
| 型号 | ISO1540DR（双向 I2C 隔离器，SOIC-8） |
| VCC1 / VCC2 | +5V_CLEAN / 3V3（两侧 3.0~5.5V 独立，自动电平适配） |
| 次级上拉 | SCL 4.7kΩ（R8）、SDA 4.7kΩ（R7）→ 3V3 |
| 最大速率 | 1MHz（本项目 I2C 400kHz 以内） |

> ISO1540 两侧为独立总线，内部高压电容只传交流信号，直流上拉不穿透，故**次级侧必须独立上拉**（R7/R8 已加）。

## 8. 失效安全分析 (Fail-Safe)

| 项 | 机制 | 失效安全态 |
|---|---|---|
| 上电/复位 | top 板 GPIO 默认 Low → TLP281 截止 → 栅极上拉至 12V | 全部 P-MOS 截止 ✅ |
| 栅极悬空保护 | 每路栅极 4.7k/10k 上拉至各自源极母线 | 光耦截止时 Vgs=0 强制关断 ✅ |
| 泵干转保护 | 软件互锁（top 板 `Bsp_Valve_AnyOn()`） | 无阀开则拒绝起泵 ✅ |
| 12V 过压 | D6 TVS 钳位 | 保护后级 ✅ |
| 过流 | F1 自恢复保险丝 | 自动恢复 ✅ |
| 隔离失效 | ISO1540 / TLP281 / 隔离 DC-DC | 泵/阀回路与 MCU 无电气直连 ✅ |
| 负载短路 | PPTC + TVS + 续流二极管 | 短路限流 ✅ |

## 10. 布局与工艺建议 (Layout & Assembly)

  · **PGND 分区**：12V 功率回路（泵/阀/续流）与隔离 5V 区域物理分区，采样电阻 10mΩ 用开尔文走线连至 INA226 IN±，避免大电流铜箔压降进入测量路径。
  · **隔离带**：U8 / TLP281 / ISO1540 下方保持完整隔离缝隙（creepage ≥ 6mm），ISO_GND 与 PGND 铜皮严禁搭接。
  · **功率线宽**：12V 主干、泵/阀输出按 ≥2A 核算线宽（1oz 铜 ≥1.5mm），端子侧加厚。
  · **去耦**：每颗 INA226 VS 旁 100nF 紧贴；3V3 输出 C15/C16 紧贴 U14。
  · **续流二极管**：D1~D5/U5 尽量靠近端子座，缩短换流回路。
  · **焊接**：采样电阻 U12/U1 用低温工艺，避免阻值漂移；AO4407A 为 SOIC-8，注意散热焊盘。
  · **H1 排针**：靠近板边，便于与 top 板叠插；+5V_CLEAN 双针并联降低接触电阻。
